# Security

Lukia has no server, no account and no telemetry. Books stay on the device. The
only network traffic is a word or passage you ask about, sent to the dictionary
or translation service you chose.

## Reporting a vulnerability

Open a [private security advisory](https://github.com/temez26/lukia/security/advisories/new),
not a public issue. Include what you did, what happened, the platform and the
version (Settings > About).

This is a one-person project: expect a reply within a week.
